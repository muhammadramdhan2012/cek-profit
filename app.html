    Cara unduh laporan

    Nama menu di Seller Centre bisa sedikit berubah. Unduh untuk periode yang sama di semua laporan.

    Shopee · Laporan Penghasilan wajib

    1. Seller Centre → Keuangan → Penghasilan Saya.
    2. Tab Sudah Dilepas, pilih periode.
    3. Unduh/Export, lalu unduh dari daftar laporan.

    Berisi sheet Summary dan Penghasilan.

    TikTok Shop · Laporan Penghasilan wajib

    1. Seller Center → Keuangan → Transaksi.
    2. Pilih rentang tanggal (sekitar 3 bulan per file), lalu Unduh.
    3. Unggah semua file sekaligus. Pesanan Tokopedia ikut di sini.

    Nama file biasanya income_…, berisi sheet Detail pesanan.

    Shopee · Export pesanan disarankan

    1. Seller Centre → Pesanan Saya → Export.
    2. Pilih periode yang sama dengan laporan penghasilan.

    Memberi jumlah barang dan SKU per pesanan. Tanpa file ini, jumlah tiap produk Shopee dianggap 1.

    TikTok Shop · Export pesanan disarankan

    1. Seller Center → Pesanan → Kelola pesanan.
    2. Ekspor → CSV untuk periode yang sama.

    Laporan penghasilan TikTok sering tidak mencantumkan produk. File ini melengkapinya.

    Retur & pengembalian opsional

    1. Shopee: Pesanan → Pengembalian/Pembatalan → Export.
    2. TikTok: Pesanan → Pengembalian → ekspor CSV.

    Dipakai untuk menandai barang retur yang tidak kembali.

    Template modal per produk opsional

    1. Setelah laporan diunggah, klik Unduh template modal di langkah 2.
    2. Isi kolom Modal per unit (Rp), simpan, lalu unggah lagi di sini.

    Modal tersimpan di browser ini untuk kunjungan berikutnya.

    Hasil adalah estimasi dari laporan dan pengaturan Anda, bukan nasihat keuangan atau pajak.
