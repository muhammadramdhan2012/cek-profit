1. Unggah laporan

Tarik file ke sini atau

Boleh banyak file sekaligus. File yang sama tidak dihitung dua kali.

File apa saja yang bisa dibaca?
  • Shopee – Laporan Penghasilan (Keuangan → Penghasilan Saya → Sudah Dilepas → unduh). Berisi sheet Summary dan Penghasilan.
  • Shopee – Pengembalian Barang/Dana (file Order.return_refund…).
  • TikTok Shop – Laporan Penghasilan (file income_…, sheet Detail pesanan).
  • TikTok Shop – Retur (CSV Pesanan yang Barang/Dananya Dikembalikan).

    2. Atur modal

    File marketplace tidak berisi harga beli. Modal dihitung dari harga acuan pemasok (misalnya harga sampul) dikurangi diskon pemasok Anda.

    Ganti sesuai diskon dari pemasok Anda
    Kosong/0 = belum dihitung
    Shopee tidak mencatat harga sebelum diskon, jadi isi pola harga Anda. Periode dipilih menurut tanggal pesanan.
    Mulai tanggalKenaikan harga %Diskon toko %
    TikTok mencatat harga sebelum diskon. 100 = harga coret sama dengan harga sampul.

    Hasil adalah estimasi dari laporan yang Anda unggah dan pengaturan modal Anda, bukan nasihat keuangan atau pajak.
