    Cara unduh laporan

    Nama menu di Seller Centre bisa sedikit berbeda dari waktu ke waktu. Unduh untuk periode yang sama di semua laporan.

    Shopee · Laporan Penghasilan

    1. Seller Centre → Keuangan → Penghasilan Saya.
    2. Pilih tab Sudah Dilepas dan periode tanggal.
    3. Klik Unduh/Export, lalu unduh file dari daftar laporan.

    File berisi sheet Summary dan Penghasilan.

    Shopee · Pengembalian

    1. Seller Centre → Pesanan → Pengembalian/Pembatalan.
    2. Pilih periode, lalu Export.

    Nama file biasanya Order.return_refund…

    TikTok Shop · Laporan Penghasilan

    1. Seller Center → Keuangan → Transaksi/Laporan.
    2. Pilih rentang tanggal (maksimal sekitar 3 bulan per file), lalu Unduh.
    3. Unggah semua file per periode sekaligus.

    Nama file biasanya income_…, berisi sheet Detail pesanan.

    TikTok Shop · Retur

    1. Seller Center → Pesanan → Pengembalian.
    2. Export daftar sebagai CSV.

    Nama file biasanya Pesanan yang Barang/Dananya Dikembalikan…csv

    Hasil adalah estimasi dari laporan yang Anda unggah dan pengaturan modal Anda, bukan nasihat keuangan atau pajak.

    Format laporan marketplace bisa berubah. Jika file gagal dibaca, laporkan lewat halaman GitHub proyek ini.
